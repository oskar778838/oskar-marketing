# oskarmarketing.bio

Premium bio site for [@oskarmarketing](https://www.tiktok.com/@oskarmarketing).
Single-page editorial portfolio — Vite + TypeScript + Three.js + GSAP.

See [docs/BUILD-NOTES.md](docs/BUILD-NOTES.md) for the full build rationale and
[research/REFERENCES.md](research/REFERENCES.md) for design-language references.

## Quick start
```
npm install
npm run dev
```

## Deploy
Push to `main` — GitHub Action builds and publishes to Pages.
Set repo Settings → Pages → Source to **GitHub Actions**.
